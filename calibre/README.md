# Calibre

Quickly search and open books in Calibre library. Type `/cb` in the launcher.

## Plugin

| Field           | Value                  |
| --------------- | ---------------------- |
| ID              | `congluantran/calibre` |
| Launcher Prefix | `/cb`                  |

## Requirements

Install `calibre` on `PATH`.

## Usage

Open the launcher and type `/cb`, followed by an optional search filter.
Press Enter to open the selected book by the default opener of its type.

## Notes

- For search filter expression, see [the relevant section](https://manual.calibre-ebook.com/gui.html#search-sort)
  from Calibre User Manual.
- Currently, the plugin only searches and opens books already added to Calibre
  library. Other functionalities might be added in the future
- Currently, the plugin only uses Calibre default library stored in Calibre own
  settings.
- Currently, Calibre Content Server is not supported.
